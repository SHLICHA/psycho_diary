# 📋 Спецификация обработчиков: `bot/handlers/tasks.py`

Данный документ описывает все обработчики (handlers) в модуле `bot/handlers/tasks.py`.  
Охватывает: функционал, входные и выходные события, переходы и обработку ошибок.

> ✅ Обновлено: 2025-09-09

---

## 🧩 `show_tasks`
> Показывает текущие активные задания с пагинацией.

- **Функционал**:
  - Получает список активных заданий пользователя.
  - Если задания есть — показывает первое с клавиатурой пагинации.
  - Если нет — показывает "Нет активных заданий" и кнопку "История заданий", если есть завершённые/пропущенные.

- **Вход**:
  - `callback_data`: `tasks` или `back_to_tasks`
  - Триггер: нажатие кнопки "Задания" или возврат из другого меню.

- **Выход**:
  - Сообщение: `task_assigned` (с названием и описанием)
  - Клавиатура: `get_task_pagination_keyboard`
  - При отсутствии заданий: `get_task_main_menu_keyboard` с опциональной кнопкой истории

---

## ⏩ `paginate_tasks`
> Пагинация между активными заданиями.

- **Функционал**:
  - Переключает между активными заданиями по кругу.
  - Отображает текущее задание с обновлённой клавиатурой.

- **Вход**:
  - `callback_data`: `tasks_paginate:next:{current_index}` или `tasks_paginate:prev:{current_index}`

- **Выход**:
  - При успехе: `task_assigned` с новым заданием
  - При отсутствии заданий: `task_no_active` + `get_back_keyboard`
  - При ошибке: `error_generic`

---

## 🔍 `view_specific_task`
> Просмотр конкретного задания из списка.

- **Функционал**:
  - Отображает детали одного задания.
  - Предоставляет кнопки "Выполнить", "Пропустить", "Удалить".

- **Вход**:
  - `callback_data`: `view_task:{task_id}`

- **Выход**:
  - Сообщение: `task_assigned`
  - Клавиатура: `get_task_detail_keyboard`
  - При ошибке: `task_not_found` или `error_generic`

---

## ✅ `start_task_completion`
> Начинает процесс выполнения задания.

- **Функционал**:
  - Устанавливает состояние `TaskStates.waiting_for_task_completion`.
  - Сохраняет `task_id` и описание в FSM.
  - Запрашивает у пользователя текст выполнения.

- **Вход**:
  - `callback_data`: `complete_task:{task_id}`

- **Выход**:
  - Переход в состояние: `TaskStates.waiting_for_task_completion`
  - Сообщение: `ask_task_completion_with_context`
  - Клавиатура: `get_cancel_keyboard`
  - При ошибке: `task_not_found` (всплывающее уведомление)

---

## 📥 `process_task_completion`
> Обрабатывает текст выполнения задания.

- **Функционал**:
  - Проверяет длину и пустоту текста.
  - Сохраняет текст выполнения в FSM.
  - Переходит к следующему шагу: описание ощущений.

- **Вход**:
  - Состояние: `TaskStates.waiting_for_task_completion`
  - Тип события: `message.text`

- **Выход**:
  - Переход в состояние: `TaskStates.describing_feelings`
  - Сообщение: `ask_feelings_description`
  - Клавиатура: `get_cancel_keyboard`

---

## 💭 `process_feelings_description`
> Обрабатывает описание ощущений при выполнении задания.

- **Функционал**:
  - Проверяет ввод.
  - Отправляет `processing`-сообщение.
  - Вызывает `task_service.complete_task` для сохранения и анализа.
  - Очищает состояние.

- **Вход**:
  - Состояние: `TaskStates.describing_feelings`
  - Тип события: `message.text`

- **Выход**:
  - При успехе: `task_completed` + обновление интерфейса
  - При ошибке: `error_processing`
  - Использует `status_message` для обновления

---

## ⏭ `skip_task`
> Пропускает задание.

- **Функционал**:
  - Отмечает задание как пропущенное через `task_service.skip_task`.
  - Возвращает в список активных заданий.
  - Если заданий не осталось — показывает `task_no_active`.

- **Вход**:
  - `callback_data`: `skip_task:{task_id}`

- **Выход**:
  - Всплывающее уведомление: `task_skipped`
  - Обновление сообщения: новое задание или `task_no_active`
  - При ошибке: `task_not_found` (всплывающее)

---

## 🗑 `delete_task`
> Запрашивает подтверждение удаления задания.

- **Функционал**:
  - Показывает сообщение с подтверждением.
  - Предоставляет кнопки "Да, удалить" и "Отмена".

- **Вход**:
  - `callback_data`: `delete_task:{task_id}`

- **Выход**:
  - Сообщение: `confirm_delete_task`
  - Клавиатура: `get_confirm_delete_task_keyboard`

---

## ✅ `confirm_delete_task`
> Подтверждает удаление задания.

- **Функционал**:
  - Удаляет задание через `task_service.delete_task`.
  - Показывает результат и кнопку "Назад".

- **Вход**:
  - `callback_data`: `confirm_delete_task:{task_id}`

- **Выход**:
  - При успехе: `task_deleted` + `get_back_keyboard`
  - При ошибке: `task_not_found` (всплывающее)

---

## ❌ `cancel_delete_task`
> Отменяет удаление задания.

- **Функционал**:
  - Отменяет процесс удаления.
  - Возвращает к предыдущему сообщению.

- **Вход**:
  - `callback_data`: `cancel_delete_task`

- **Выход**:
  - Сообщение: `task_delete_cancelled`
  - Клавиатура: `get_back_keyboard`

---

## 📚 `show_task_history_main`
> Показывает историю выполненных и пропущенных заданий.

- **Функционал**:
  - Получает все завершённые и пропущенные задания.
  - Сортирует по дате (от новых к старым).
  - Сохраняет список ID в FSM для пагинации.
  - Показывает первое задание с клавиатурой пагинации.

- **Вход**:
  - `callback_data`: `task_history_main`

- **Выход**:
  - При наличии: первое задание + `get_task_history_list_keyboard`
  - При отсутствии: `task_history_empty` + `get_task_history_main_keyboard`
  - Сохраняет `task_history_ids` в FSM

---

## ⏩ `paginate_task_history`
> Пагинация по истории заданий.

- **Функционал**:
  - Использует список ID из FSM.
  - Показывает детали задания по индексу.
  - Обновляет клавиатуру с текущим статусом.

- **Вход**:
  - `callback_data`: `task_history_paginate:{index}`

- **Выход**:
  - Сообщение: детали задания (через `_format_task_history_detail`)
  - Клавиатура: `get_task_history_list_keyboard`
  - При ошибке: `error_generic` или `task_not_found`

---

## 🔁 `restore_skipped_task`
> Восстанавливает пропущенное задание.

- **Функционал**:
  - Меняет статус задания с `skipped` на `active`.
  - Удаляет ID из списка истории в FSM.
  - Возвращает в список активных заданий.

- **Вход**:
  - `callback_data`: `task_history_restore:{task_id}`

- **Выход**:
  - При успехе: всплывающее уведомление `task_restored`, вызов `show_tasks`
  - При ошибке: `task_not_found_or_not_skipped` (всплывающее)

---

## 🔍 `view_detailed_task_analysis`
> Показывает детальный анализ выполнения задания.

- **Функционал**:
  - Проверяет, что задание выполнено.
  - Получает `TaskCompletion` и `TaskCompletionAnalysis`.
  - Отображает развернутый анализ, если он есть.

- **Вход**:
  - `callback_data`: `view_detailed_task_analysis:{task_id}`

- **Выход**:
  - Сообщение: `detailed_task_analysis_header` + `analysis.detailed_analysis`
  - Или: `task_analysis_no_details`
  - Клавиатура: кнопка "Назад"
  - При ошибке: всплывающие уведомления

---

## 🧩 `_format_task_history_detail`
> Вспомогательная функция: форматирует детали задания из истории.

- **Функционал**:
  - Формирует текст с названием, датами, статусом, описанием, выполнением и ощущениями.
  - Обрабатывает отсутствие данных.

- **Вход**:
  - `task`: объект `TherapyTask`
  - `language`: язык интерфейса
  - `state`: FSMContext (для совместимости)

- **Выход**:
  - Отформатированный текст с разметкой
  - При ошибке: `error_loading_task_details`

---

## 🧪 Тестовые сценарии (для QA)

| Сценарий | Проверка |
|--------|--------|
| Активные задания | Показываются с пагинацией |
| Выполнение задания | Текст → ощущения → анализ |
| Пропуск задания | Задание исчезает, обновляется интерфейс |
| Удаление задания | Подтверждение, удаление, возврат |
| История заданий | Показывается список, можно пагинировать |
| Восстановление задания | Пропущенное задание возвращается в активные |
| Детальный анализ | Показывается только для выполненных заданий |
