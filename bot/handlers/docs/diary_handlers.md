# 📋 Спецификация обработчиков: `bot/handlers/diary.py` (обновленная версия)

Данный документ описывает обновленные обработчики в модуле `bot/handlers/diary.py`.  
Включает улучшения: умные подсказки, rate limiting, обработку ошибок.

> ✅ Обновлено: 2025-09-09  
> 🔄 Изменения: Умные подсказки, декораторы ошибок, rate limiting

---

## 🧩 `new_entry_simple`

> Упрощенное создание записи с умными подсказками.

- **Функционал**:
  - Использует `SmartPromptManager` для генерации контекстных подсказок.
  - Устанавливает состояние ожидания текста записи.
  - Автоматический fallback на стандартный запрос при ошибках.

- **Вход**:
  - `callback_data`: `new_entry`
  - Триггер: нажатие кнопки "Новая запись".

- **Выход**:
  - Переход в состояние: `DiaryStates.waiting_for_text_entry`
  - Сообщение: умная подсказка или стандартный запрос
  - Клавиатура: `get_cancel_keyboard`
  - При ошибке: fallback на стандартный запрос

---

## 📝 `process_any_entry` (обновленный)

> Обработка записей с улучшенной обработкой ошибок и rate limiting.

- **Функционал**:
  - Валидация входящих сообщений и проверка rate limits.
  - Обработка голосовых сообщений через улучшенную систему.
  - Интеграция с `SmartPromptManager` для отслеживания активности.
  - Расширенный контекст пользователя для анализа.

- **Вход**:
  - Состояние: `DiaryStates.waiting_for_text_entry`
  - Тип события: `message.text` или `message.voice`
  - Декоратор: `@async_error_handler('diary_handler')`

- **Выход**:
  - При успехе: `entry_saved` с анализом + возможное задание
  - При rate limit: `rate_limit`
  - При ошибке валидации: соответствующие сообщения об ошибках
  - Уведомление `SmartPromptManager` о сохраненной записи

## ✅ `confirm_delete_specific_entry` (обновленный)

> Улучшенное подтверждение удаления конкретной записи.

- **Функционал**:
  - Валидация формата даты из callback_data.
  - Удаление записи через сервис с обновлением combined entry.
  - Навигация обратно к записям дня или календарю.

- **Вход**:
  - `callback_data`: `confirm_delete_specific_entry:{entry_id}:{date_iso}`

- **Выход**:
  - При успехе: `entry_deleted_success` + обновленная навигация
  - При ошибке: `error_processing` + возврат к навигации
  - При неверном формате даты: `error_generic` (всплывающее)

## 🔧 Технические улучшения

- **Умные подсказки**: Интеграция с `SmartPromptManager`
- **Rate Limiting**: Ограничение 3 записей в минуту на пользователя
- **Обработка ошибок**: Декоратор `@async_error_handler`
- **Валидация**: Улучшенная проверка форматов данных
- **Фоновые задачи**: Асинхронный пересчет анализа
- **Локализация**: Поддержка временных зон в отображении
