# 📄 Спецификация обработчиков: `bot/handlers/diary.py`

Данный документ описывает все обработчики (handlers) и ключевые функции в модуле `bot/handlers/diary.py`.  
Включает: функционал, входные и выходные события, состояния, переходы.

> ✅ Обновлено: 2025-09-09

---

## ✍️ `new_entry`
> Запускает процесс создания новой записи.

- **Функционал**:
  - Устанавливает состояние `DiaryStates.waiting_for_text_entry`.
  - Показывает пользователю приглашение ввести текст или голос.
  - Предоставляет кнопку "Отмена".

- **Вход**:
  - `callback_data`: `new_entry`
  - Триггер: нажатие кнопки "Создать запись" в главном меню.

- **Выход**:
  - Переход в состояние: `DiaryStates.waiting_for_text_entry`
  - Сообщение: `ask_entry`
  - Клавиатура: `get_cancel_keyboard`
  - При ошибке: `error_generic`

---

## 📥 `process_any_entry`
> Обрабатывает входящее сообщение (текст или голос) и создаёт запись.

- **Функционал**:
  - Проверяет валидность сообщения.
  - Для голоса: распознаёт через Yandex SpeechKit, форматирует через DeepSeek.
  - Для текста: использует как есть.
  - Создаёт запись через `diary_service` с корректным `entry_datetime`.
  - Запускает анализ через `_process_analysis_result`.

- **Вход**:
  - Состояние: `DiaryStates.waiting_for_text_entry`
  - Тип события: `message.text` или `message.voice`

- **Выход**:
  - При успехе: вызывает `_process_analysis_result`
  - При ошибке: показывает `error_processing`, очищает состояние
  - Показывает `processing` во время обработки

---

## ❓ `process_clarification_answers`
> Обрабатывает ответы пользователя на уточняющие вопросы.

- **Функционал**:
  - Получает ID записи и вопросы из FSM.
  - Сохраняет ответы в `DiaryEntry.clarification_answers`.
  - Формирует промпт для анализа с учётом уточнений.
  - Запускает повторный анализ записи.

- **Вход**:
  - Состояние: `DiaryStates.asking_clarifying_questions`
  - Тип события: `message.text`

- **Выход**:
  - Сохранение ответов в БД
  - Вызов `_process_analysis_result`
  - При ошибке: `error_processing`, очистка состояния

---

## ⚠️ `handle_invalid_entry_type`
> Обрабатывает сообщения с неподдерживаемым типом контента.

- **Функционал**:
  - Отлавливает, если пользователь прислал фото, документ и т.п.
  - Отправляет сообщение: "Пожалуйста, отправьте текст или голосовое сообщение."

- **Вход**:
  - Состояние: `DiaryStates.waiting_for_text_entry`
  - Тип события: любой, кроме `text` или `voice`

- **Выход**:
  - Сообщение: `invalid_input`
  - Использует `edit_or_send_message` для надёжной доставки
  - Не меняет состояние (позволяет повторить ввод)

---

## 🔄 `select_day`
> Открывает пагинацию по записям за день. Показывает первую запись.

- **Функционал**:
  - Получает все записи пользователя за выбранную дату.
  - Сортирует по времени создания.
  - Показывает первую запись с клавиатурой пагинации.
  - Если записей нет — показывает сообщение "Нет записей".

- **Вход**:
  - `callback_data`: `calendar_select_day:year:month:day`
  - Триггер: выбор дня в календаре архива.

- **Выход**:
  - При успехе: вызывает `_show_entry_page`
  - При ошибке: показывает `archive_empty` или `error_generic`
  - Клавиатура: `get_entry_pagination_keyboard`

---

## ⏩ `entry_next`
> Показывает следующую запись в пагинации.

- **Функционал**:
  - Находит текущую запись по `entry_id`.
  - Получает все записи за день.
  - Определяет индекс следующей записи.
  - Показывает следующую запись через `_show_entry_page`.

- **Вход**:
  - `callback_data`: `entry_next:{entry_id}`

- **Выход**:
  - При успехе: `_show_entry_page` с новой записью.
  - При достижении конца: всплывающее уведомление "Это последняя запись."
  - При ошибке: `error_generic`

---

## ⏪ `entry_prev`
> Показывает предыдущую запись в пагинации.

- **Функционал**:
  - Аналогично `entry_next`, но в обратном направлении.
  - Проверяет, не является ли текущая запись первой.

- **Вход**:
  - `callback_data`: `entry_prev:{entry_id}`

- **Выход**:
  - При успехе: `_show_entry_page` с предыдущей записью.
  - При достижении начала: всплывающее уведомление "Это первая запись."
  - При ошибке: `error_generic`

---

## ✏️ `entry_edit`
> Начинает процесс редактирования конкретной записи.

- **Функционал**:
  - Устанавливает состояние `DiaryStates.waiting_for_entry_edit`.
  - Сохраняет `entry_id` и дату в FSM.
  - Отправляет пользователю текущий текст записи для редактирования.
  - Предоставляет клавиатуру отмены.

- **Вход**:
  - `callback_data`: `entry_edit:{entry_id}`
  - Из пагинации (`get_entry_pagination_keyboard`)

- **Выход**:
  - Переход в состояние: `DiaryStates.waiting_for_entry_edit`
  - Отправка сообщения: `ask_entry_edit_with_text`
  - Клавиатура: `get_cancel_keyboard`

---

## 📥 `process_entry_edit`
> Обрабатывает введённый пользователем текст после редактирования.

- **Функционал**:
  - Получает `entry_id` из состояния.
  - Обновляет текст записи через `diary_service.update_entry_text`.
  - Обновляет `CombinedDiaryEntry`.
  - Возвращает в пагинацию через `_show_entry_page`.

- **Вход**:
  - Состояние: `DiaryStates.waiting_for_entry_edit`
  - Тип события: `message.text`

- **Выход**:
  - При успехе: `_show_entry_page` с обновлённой записью.
  - При ошибке: `error_processing` + переход в главное меню.
  - Очистка состояния: `state_manager.clear_state`

---

## 🗑 `entry_delete_confirm`
> Запрашивает подтверждение удаления конкретной записи.

- **Функционал**:
  - Показывает сообщение с подтверждением.
  - Использует универсальную клавиатуру подтверждения.
  - Поддерживает возврат к пагинации.

- **Вход**:
  - `callback_data`: `entry_delete_confirm:{entry_id}`

- **Выход**:
  - Сообщение: `confirm_delete_entry_prompt`
  - Клавиатура: `get_delete_entry_confirmation_keyboard`
  - Сохраняет `target_date` для возврата

---

## ✅ `confirm_delete_specific_entry`
> Подтверждает удаление записи и возвращает в пагинацию.

- **Функционал**:
  - Удаляет запись и связанные объекты через `diary_service.delete_entry_and_update_combined`.
  - Обновляет `CombinedDiaryEntry`.
  - Возвращает в пагинацию с оставшимися записями.
  - Если записей не осталось — показывает `archive_empty`.

- **Вход**:
  - `callback_data`: `confirm_delete_specific_entry:{entry_id}:{iso_date}`

- **Выход**:
  - При успехе: `_show_entry_page` или `archive_empty`
  - При ошибке: `error_processing` + попытка возврата
  - Всплывающее уведомление: `entry_deleted_success`

---

## ❌ `cancel_delete_specific_entry`
> Отменяет удаление конкретной записи.

- **Функционал**:
  - Отменяет процесс удаления.
  - Возвращает в пагинацию с текущей записью.

- **Вход**:
  - `callback_data`: `cancel_delete_specific_entry:{entry_id}:{iso_date}`

- **Выход**:
  - При успехе: `_show_entry_page` с первой записью.
  - При ошибке: `error_generic`
  - Всплывающее уведомление: `entry_delete_cancelled`

---

## 🔁 `reanalyze_day`
> Запускает пересчёт анализа всего дня.

- **Функционал**:
  - Проверяет, был ли день уже проанализирован (`is_analyzed`).
  - Если нет — создаёт `CombinedDiaryEntry`.
  - Запускает имитацию анализа (заглушка).
  - Пересоздаёт `PsychoAnalysis` для всех записей.
  - Возвращает в пагинацию.

- **Вход**:
  - `callback_data`: `reanalyze_day:year:month:day`

- **Выход**:
  - При успехе: всплывающее уведомление `analysis_recalculated`, возврат в пагинацию.
  - Если уже проанализирован: `analysis_already_done`
  - Использует `psycho_analysis_service.create_or_update_analysis`

---

## 🗑 `delete_selected_entry`
> Устаревший хендлер удаления записи или дня. **Должен быть удалён.**

- **Функционал**:
  - Обрабатывает `delete_entry:...` и может удалять либо конкретную запись, либо весь день.
  - Дублирует логику `request_delete_entire_day` и `entry_delete_confirm`.

- **Вход**:
  - `callback_data`: `delete_entry:year:month:day` или `delete_entry:entry_id`

- **Выход**:
  - Вызов `confirm_delete_entire_day` или `entry_delete_confirm`
  - **Конфликтует с новой пагинацией**

> ❌ **Рекомендация**: удалить. Заменён на `entry_delete_confirm` и `request_delete_entire_day`.

## 📁 `request_delete_entire_day`
> Запрашивает подтверждение удаления всех записей за день.

- **Функционал**:
  - Парсит дату из `callback_data` в формате `YYYY-MM-DD`.
  - Показывает подтверждающее сообщение с датой.
  - Предоставляет кнопки "Да, удалить" и "Отмена".

- **Вход**:
  - `callback_data`: `delete_entire_day:{iso_date}`

- **Выход**:
  - Сообщение: `confirm_delete_entire_day_prompt`
  - Клавиатура: с `confirm_delete_entire_day:{iso_date}`
  - Поддерживает неправильный формат даты

---

## 🧹 `confirm_delete_entire_day`
> Подтверждает удаление всех записей за день.

- **Функционал**:
  - Удаляет все записи, связанные объекты и `CombinedDiaryEntry`.
  - Возвращает в календарь через `get_smart_calendar_keyboard`.

- **Вход**:
  - `callback_data`: `confirm_delete_entire_day:{iso_date}`

- **Выход**:
  - При успехе: обновлённый календарь.
  - При ошибке: `error_generic`
  - Использует `diary_service.delete_all_entries_for_day`

---

## 🔍 `view_day_insights`
> Показывает инсайты пользователя за день.

- **Функционал**:
  - Получает все записи за день.
  - Через `diary_service.get_insights_for_entries` — извлекает инсайты.
  - Формирует сообщение с инсайтами.
  - Показывает клавиатуру с возвратом.

- **Вход**:
  - `callback_data`: `view_day_insights:year:month:day`

- **Выход**:
  - Сообщение с инсайтами
  - Клавиатура: `get_back_to_edit_day_keyboard`
  - Возврат: в пагинацию

---

## 🔎 `view_day_keypoints`
> Показывает ключевые моменты за день.

- **Функционал**:
  - Получает записи за день.
  - Через `diary_service.get_keypoints_for_entries` — извлекает KP.
  - Формирует сообщение.
  - Показывает кнопку возврата.

- **Вход**:
  - `callback_data`: `view_day_keypoints:year:month:day`

- **Выход**:
  - Сообщение с ключевыми моментами
  - Клавиатура: `get_back_to_edit_day_keyboard`
  - Возврат: в пагинацию

---

## 📝 `_show_entry_page`
> Вспомогательная функция: отображает одну запись с пагинацией.

- **Функционал**:
  - Формирует текст записи + анализ (если есть).
  - Генерирует `get_entry_pagination_keyboard`.
  - Использует `edit_or_send_message` для надёжного обновления интерфейса.

- **Вход**:
  - `entry`, `entries`, `user`, `target_date`, `language`

- **Выход**:
  - Редактирование или отправка сообщения
  - Использует `edit_or_send_message` (не `safe_edit_message_text`)

---

## 🧩 `_process_analysis_result`
> Обрабатывает результат анализа записи (от DeepSeek).

- **Функционал**:
  - Обновляет `PsychoAnalysis`.
  - Создаёт/обновляет `CombinedDiaryEntry`.
  - Генерирует задания через `task_service`.
  - Формирует итоговое сообщение с рекомендациями.

- **Вход**:
  - `diary_entry`, `analysis_result`, `status_msg`

- **Выход**:
  - Обновлённый интерфейс с `entry_saved`
  - Клавиатура: `get_main_menu_keyboard`
  - Очистка состояния

---

## 🧪 `_reanalyze_day_background_silent`
> Фоновая задача для пересчёта CombinedDiaryEntry (заглушка).

- **Функционал**:
  - Получает объединённый текст дня.
  - Если есть изменения — запускает фоновый анализ.
  - Не отправляет сообщений пользователю.

- **Вход**:
  - Вызывается программно (не через callback)
  - Аргументы: `user`, `target_date`, `language`

- **Выход**:
  - Обновление `CombinedDiaryEntry`
  - Логирование результата
  - Никаких действий с интерфейсом

---

## 🧪 Тестовые сценарии (для QA)

| Сценарий | Проверка |
|--------|--------|
| Новая запись | Текст/голос → анализ |
| Редактирование | Текст обновился, анализ пересчитан |
| Удаление записи | Запись исчезла, осталась пагинация |
| Удаление дня | Все записи удалены, возврат в календарь |
| Уточняющие вопросы | Показываются, ответы сохраняются |
| Пересчёт анализа | Всплывающее уведомление, анализ обновлён |
| День без записей | Сообщение `archive_empty` |
| Одна запись | Нет кнопок `◀️/▶️` |
