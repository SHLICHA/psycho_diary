# 📋 Спецификация обработчиков: `bot/handlers/diary.py`

Данный документ описывает все обработчики (handlers) в модуле `bot/handlers/diary.py`.  
Охватывает: функционал, входные и выходные события, переходы и обработку ошибок.

> ✅ Обновлено: 2025-09-09

---

## 🧩 `new_entry`
> Инициирует создание новой записи в дневнике.

- **Функционал**:
  - Устанавливает состояние `DiaryStates.waiting_for_text_entry`.
  - Запрашивает у пользователя текст или голосовое сообщение.

- **Вход**:
  - `callback_data`: `new_entry`
  - Триггер: нажатие кнопки "Новая запись" из главного меню.

- **Выход**:
  - Переход в состояние: `DiaryStates.waiting_for_text_entry`
  - Сообщение: `ask_entry`
  - Клавиатура: `get_cancel_keyboard`
  - При ошибке: `error_generic` (всплывающее)

---

## 📝 `process_any_entry`
> Обрабатывает текстовые и голосовые записи дневника.

- **Функционал**:
  - Валидирует входящее сообщение.
  - Обрабатывает голосовые сообщения через распознавание речи.
  - Создает запись в дневнике.
  - Запускает анализ через ИИ.
  - Обрабатывает результат анализа.

- **Вход**:
  - Состояние: `DiaryStates.waiting_for_text_entry`
  - Тип события: `message.text` или `message.voice`

- **Выход**:
  - При успехе: `entry_saved` с анализом + возможное задание от ИИ
  - При необходимости уточнений: переход в `DiaryStates.asking_clarifying_questions`
  - При ошибке: `error_processing`
  - Использует `status_message` для отображения процесса

---

## ❓ `process_clarification_answers`
> Обрабатывает ответы на уточняющие вопросы.

- **Функционал**:
  - Принимает текстовые или голосовые ответы на уточнения.
  - Сохраняет ответы в запись.
  - Запускает анализ с учетом уточнений.

- **Вход**:
  - Состояние: `DiaryStates.asking_clarifying_questions`
  - Тип события: `message.text` или `message.voice`

- **Выход**:
  - При успехе: `entry_saved` с полным анализом
  - При ошибке: `error_processing`
  - Очищает состояние FSM

---

## 🗓 `select_day`
> Показывает записи выбранного дня с пагинацией.

- **Функционал**:
  - Получает записи за указанную дату.
  - Сортирует записи по времени создания.
  - Показывает первую запись с навигацией.

- **Вход**:
  - `callback_data`: `calendar_select_day:{year}:{month}:{day}`

- **Выход**:
  - При наличии записей: первая запись + `get_entry_page_keyboard`
  - При отсутствии: `archive_empty` + календарная навигация
  - При ошибке: `error_generic` (всплывающее)

---

## 🔬 `view_full_day_analysis`
> Показывает полный анализ дня.

- **Функционал**:
  - Получает `DailyAnalysis` для указанной даты.
  - Форматирует анализ с разделами: настроение, темы, паттерны, инсайты, рекомендации.
  - Предоставляет опцию пересчета анализа.

- **Вход**:
  - `callback_data`: `view_full_day_analysis:{year}:{month}:{day}`

- **Выход**:
  - При успехе: детализированный анализ дня
  - При отсутствии анализа: `no_full_analysis_yet` + кнопка пересчета
  - При ошибке: `error_generic` (всплывающее)

---

## ✏️ `entry_edit`
> Начинает процесс редактирования записи.

- **Функционал**:
  - Устанавливает состояние `DiaryStates.waiting_for_entry_edit`.
  - Сохраняет ID редактируемой записи в FSM.
  - Показывает текущий текст для редактирования.

- **Вход**:
  - `callback_data`: `entry_edit:{entry_id}`

- **Выход**:
  - Переход в состояние: `DiaryStates.waiting_for_entry_edit`
  - Сообщение: `ask_entry_edit_with_text` с текущим текстом
  - Клавиатура: `get_cancel_keyboard`
  - При ошибке: `error_generic` (всплывающее)

---

## ❌ `entry_delete_confirm`
> Запрашивает подтверждение удаления записи.

- **Функционал**:
  - Показывает подтверждение удаления конкретной записи.
  - Предоставляет кнопки подтверждения и отмены.

- **Вход**:
  - `callback_data`: `entry_delete_confirm:{entry_id}`

- **Выход**:
  - Сообщение: `confirm_delete_entry_prompt`
  - Клавиатура: `get_delete_entry_confirmation_keyboard`
  - При ошибке: `error_generic` (всплывающее)

---

## ⬅️ `entry_prev`
> Показывает предыдущую запись дня.

- **Функционал**:

  - Обновляет интерфейс пагинации.

- **Вход**:
  - `callback_data`: `entry_prev:{entry_id}`

- **Выход**:
  - При успехе: предыдущая запись с обновленной клавиатурой
  - При первой записи: всплывающее уведомление
  - При ошибке: `error_generic` (всплывающее)

---

## ➡️ `entry_next`
> Показывает следующую запись дня.

- **Функционал**:

  - Обновляет интерфейс пагинации.

- **Вход**:
  - `callback_data`: `entry_next:{entry_id}`

- **Выход**:
  - При успехе: следующая запись с обновленной клавиатурой
  - При последней записи: всплывающее уведомление
  - При ошибке: `error_generic` (всплывающее)

---

## 🔄 `reanalyze_day`
> Запускает пересчет анализа дня.

- **Функционал**:
  - Инициирует фоновую задачу полного анализа дня.
  - Немедленно подтверждает callback для избежания таймаута.
  - Показывает статус обработки.

- **Вход**:
  - `callback_data`: `reanalyze_day:{year}:{month}:{day}`

- **Выход**:
  - Всплывающее уведомление: `day_analysis_confirmed`
  - Сообщение статуса обработки
  - Запуск фоновой задачи анализа
  - При ошибке: `error_generic`

---

## 🗑 `delete_selected_entry`
> Обрабатывает запросы на удаление записей.

- **Функционал**:
  - Определяет тип удаления (вся день или конкретная запись).
  - Показывает соответствующие подтверждения.

- **Вход**:
  - `callback_data`: `delete_entry:{year}:{month}:{day}` или `delete_entry:{entry_id}`

- **Выход**:
  - Сообщение подтверждения удаления
  - Соответствующая клавиатура подтверждения
  - При ошибке: `error_generic` (всплывающее)

---

## 💾 `process_entry_edit`
> Обрабатывает отредактированный текст записи.

- **Функционал**:
  - Поддерживает текстовый и голосовой ввод.
  - Валидирует новый текст.
  - Обновляет запись в базе данных.
  - Возвращает к просмотру записи.

- **Вход**:
  - Состояние: `DiaryStates.waiting_for_entry_edit`
  - Тип события: `message.text` или `message.voice`

- **Выход**:
  - При успехе: обновленная запись с навигацией
  - При ошибке: `error_processing`
  - Очищает состояние FSM

---

## 📋 `request_delete_specific_entry`
> Запрос подтверждения удаления конкретной записи.

- **Функционал**:
  - Показывает подтверждение для удаления одной записи.
  - Сохраняет контекст для возврата.

- **Вход**:
  - `callback_data`: `request_delete_specific_entry:{entry_id}`

- **Выход**:
  - Сообщение: `confirm_delete_entry_prompt`
  - Клавиатура: `get_delete_entry_confirmation_keyboard`
  - При ошибке: `entry_not_found` (всплывающее)

---

## 📅 `request_delete_entire_day`
> Запрос подтверждения удаления всех записей дня.

- **Функционал**:
  - Показывает подтверждение для удаления всех записей дня.
  - Предоставляет опции подтверждения/отмены.

- **Вход**:
  - `callback_data`: `delete_entire_day:{date_str}`

- **Выход**:
  - Сообщение: `confirm_delete_entire_day_prompt`
  - Клавиатура подтверждения с возвратом в архив
  - При ошибке: `error_generic` (всплывающее)

---

## ✅ `confirm_delete_specific_entry`
> Подтверждение и выполнение удаления конкретной записи.

- **Функционал**:
  - Удаляет указанную запись.
  - Обновляет combined entry.
  - Возвращает к навигации по дню.

- **Вход**:
  - `callback_data`: `confirm_delete_specific_entry:{entry_id}:{date_str}`

- **Выход**:
  - При успехе: `entry_deleted_success` + обновленная навигация
  - При ошибке: `error_processing` + возврат к навигации
  - При отсутствии записи: `entry_not_found` (всплывающее)

---

## ✅ `confirm_delete_entire_day`
> Подтверждение и выполнение удаления всех записей дня.

- **Функционал**:
  - Удаляет все записи указанного дня.
  - Возвращает в календарь.

- **Вход**:
  - `callback_data`: `confirm_delete_entire_day:{date_str}`

- **Выход**:
  - При успехе: `day_deleted_success` + возврат в календарь
  - При ошибке: `error_processing` (всплывающее)

---

## ↩️ `cancel_delete_specific_entry`
> Отмена удаления конкретной записи.

- **Функционал**:
  - Прерывает процесс удаления.
  - Возвращает к просмотру записи.

- **Вход**:
  - `callback_data`: `cancel_delete_specific_entry:{entry_id}:{date_str}`

- **Выход**:
  - Сообщение: `entry_delete_cancelled`
  - Возврат к навигации по записям дня
  - При ошибке: `error_generic` (всплывающее)

## 🧪 Тестовые сценарии (для QA)

| Сценарий | Проверка |
|--------|--------|
| Создание записи | Текст/голос → анализ → сохранение |
| Редактирование записи | Изменение текста → сохранение → отображение |
| Удаление записи | Подтверждение → удаление → обновление интерфейса |
| Пагинация дня | Навигация между записями дня |
| Полный анализ дня | Генерация и отображение полного анализа |
| Пересчет анализа | Фоновая задача пересчета |
| Просмотр инсайтов | Отображение инсайтов за день |
| Просмотр ключевых моментов | Отображение ключевых моментов за день |
