# 📋 Спецификация обработчиков: `bot/handlers/settings.py`

Данный документ описывает все обработчики (handlers) в модуле `bot/handlers/settings.py`.  
Охватывает: функционал, входные и выходные события, переходы и обработку ошибок.

> ✅ Обновлено: 2025-09-09

---

## 🧩 `show_settings`
> Показывает главное меню настроек.

- **Функционал**:
  - Отображает основное меню настроек пользователя.
  - Показывает текущий статус уведомлений, автоанализа и премиум-доступа.

- **Вход**:
  - `callback_data`: `settings`
  - Триггер: нажатие кнопки "Настройки" из главного меню.

- **Выход**:
  - Сообщение: `settings_menu`
  - Клавиатура: `get_settings_keyboard` (адаптированная под пользователя)
  - При ошибке: `error_generic` (всплывающее уведомление)

---

## 🌐 `change_language`
> Инициирует процесс изменения языка интерфейса.

- **Функционал**:
  - Устанавливает состояние `SettingsStates.waiting_for_language_choice`.
  - Показывает доступные варианты языков.

- **Вход**:
  - `callback_data`: `settings_change_language`

- **Выход**:
  - Переход в состояние: `SettingsStates.waiting_for_language_choice`
  - Сообщение: `settings_menu`
  - Клавиатура: `get_language_selection_keyboard`
  - При ошибке: `error_generic` (всплывающее)

---

## ✅ `set_language`
> Устанавливает выбранный язык интерфейса.

- **Функционал**:
  - Сохраняет выбранный язык в профиле пользователя.
  - Очищает состояние FSM.
  - Обновляет интерфейс на выбранном языке.

- **Вход**:
  - `callback_data`: `set_language:{language_code}` (ru/en)

- **Выход**:
  - При успехе: `language_changed` + обновленная клавиатура настроек
  - При ошибке: `error_generic` (всплывающее)
  - Очищает состояние FSM

## 🏙 `enter_city_for_timezone`
> Запрашивает ввод города для определения часового пояса.

- **Функционал**:
  - Устанавливает состояние `SettingsStates.waiting_for_city_input`.
  - Запрашивает название города.

- **Вход**:
  - `callback_data`: `timezone_enter_city`

- **Выход**:
  - Переход в состояние: `SettingsStates.waiting_for_city_input`
  - Сообщение: запрос ввода города
  - Клавиатура: `get_back_keyboard`
  - При ошибке: `error_generic` (всплывающее)

---

## 📝 `process_city_input`
> Обрабатывает ввод города для определения часового пояса.

- **Функционал**:
  - Проверяет ввод на команды выхода.
  - Ищет город в кэше или через API.
  - При нахождении: показывает подтверждение.
  - При нескольких вариантах: показывает список для выбора.

- **Вход**:
  - Состояние: `SettingsStates.waiting_for_city_input`
  - Тип события: `message.text` (название города)

- **Выход**:
  - При успехе: показывает найденный часовой пояс + `get_city_timezone_confirmation_keyboard`
  - При нескольких вариантах: `get_multiple_city_timezones_keyboard`
  - При ошибке: сообщение об ошибке + повторный запрос
  - Переход в состояние: `SettingsStates.waiting_for_timezone_confirmation` (при успехе)

## ✅ `select_timezone_from_options`
> Обрабатывает выбор часового пояса из нескольких вариантов.

- **Функционал**:
  - Устанавливает выбранный часовой пояс.
  - Сохраняет изменения в профиле пользователя.
  - Возвращает в меню настроек.

- **Вход**:
  - `callback_data`: `select_timezone:{timezone_string}`

- **Выход**:
  - При успехе: `timezone_changed` + возврат в меню настроек
  - При ошибке: `error_unknown_timezone` или `error_generic` (всплывающее)
  - Очищает состояние FSM

## 📝 `edit_profile_*`
> Группа обработчиков для редактирования полей профиля.

- **Функционал**:
  - Устанавливают соответствующие состояния FSM.
  - Запрашивают ввод новых данных для поля.

- **Вход**:
  - `callback_data`: `edit_profile_name`, `edit_profile_email`, `edit_profile_dob`, `edit_profile_hobbies`, `edit_profile_life_facts`

- **Выход**:
  - Переход в состояние: `SettingsStates.waiting_for_*_input`
  - Сообщение: запрос на ввод данных + текущие значения
  - Клавиатура: `get_back_keyboard`
  - При ошибке: `error_generic` (всплывающее)

---

## 💾 `process_*_input`
> Группа обработчиков для сохранения данных профиля.

- **Функционал**:
  - Обрабатывают ввод новых данных.
  - Валидируют введенные данные.
  - Сохраняют изменения в профиле пользователя.

- **Вход**:
  - Состояние: `SettingsStates.waiting_for_*_input`
  - Тип события: `message.text`

- **Выход**:
  - При успехе: `profile_updated` + возврат в меню редактирования профиля
  - При ошибке: сообщение об ошибке + повторный запрос
  - Очищает состояние FSM
