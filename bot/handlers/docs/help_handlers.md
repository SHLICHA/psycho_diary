# ❓ Спецификация обработчиков: `bot/handlers/help.py`

Данный документ описывает все обработчики (handlers) в модуле `bot/handlers/help.py`.  
Охватывает: функционал, входные и выходные события, переходы и обработку ошибок.

> ✅ Обновлено: 2025-09-09

---

## 🆘 `show_help`
> Показывает главное меню помощи.

- **Функционал**:
  - Отображает приветственное сообщение с описанием функций бота.
  - Предоставляет клавиатуру навигации по разделам помощи.
  - Поддерживает вызов как через команду `/help`, так и через callback.

- **Вход**:
  - `callback_data`: `help`
  - Или команда: `/help`
  - Триггер: нажатие кнопки "Помощь" или ввод команды.

- **Выход**:
  - Сообщение: `help_main_text`
  - Клавиатура: `get_help_keyboard`
  - При ошибке: `error_generic`

---

## ❓ `show_faq`
> Показывает раздел "Часто задаваемые вопросы".

- **Функционал**:
  - Отображает текст с ответами на популярные вопросы.
  - Предоставляет кнопку "Назад" для возврата в главное меню помощи.

- **Вход**:
  - `callback_data`: `help_faq`

- **Выход**:
  - Сообщение: `help_faq_text`
  - Клавиатура: `get_help_section_keyboard`
  - Всплывающее уведомление: "FAQ показан"
  - При ошибке: `error_generic`

## 🔙 `back_to_main_help`
> Возвращает пользователя в главное меню помощи.

- **Функционал**:
  - Редактирует текущее сообщение, заменяя его на главное меню помощи.
  - Используется из любого подраздела помощи.

- **Вход**:
  - `callback_data`: `help_back_to_main`

- **Выход**:
  - Сообщение: `help_main_text` (или аналог)
  - Клавиатура: `get_help_keyboard`
  - При ошибке: `error_generic`

## 🧪 Тестовые сценарии (для QA)

| Сценарий | Проверка |
|--------|--------|
| Вызов помощи | Через `/help` и кнопку "Помощь" — одинаковый результат |
| Переход в FAQ | Сообщение отображается, есть кнопка "Назад" |
| Навигация по разделам | Все разделы доступны, тексты загружаются |
| Возврат в главное меню | Кнопка "Назад" работает из всех разделов |
| Ошибка в callback | Не падает, показывает `error_generic` |
